# Shahad Turki Alshammari | Portfolio

Personal portfolio website showcasing my background, projects, and technical interests in Artificial Intelligence.

🌐 **Live Portfolio:** [View My Portfolio](https://0shahad0.github.io/Shahad-Portfolio/)

## Overview

This repository contains the source code for my personal portfolio website, built with HTML, CSS, and vanilla JavaScript. It presents my professional profile, selected projects, and technical skills in a responsive, user-friendly interface.

## Tech Stack

- **HTML5** — Page structure and content
- **CSS3** — Styling and responsive layout
- **JavaScript** — Interactive features and dynamic behavior

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/0Shahad0/Shahad-Portfolio.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.

## Project Structure

```text
Shahad-Portfolio/
├── assets/       # Images and other static assets
├── index.html    # Main portfolio page
├── styles.css     # Website styles
└── script.js     # Interactive functionality
```

## Customization

- Update portfolio content and links in `index.html`.
- Add or replace images and other assets in `assets/`.
- Modify the styling in the CSS file.
- Update interactive features in the JavaScript file.

## Deployment

The website is hosted using **GitHub Pages** and is accessible through the live portfolio link above.
