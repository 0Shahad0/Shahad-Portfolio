# Shahad Turki Alshammari — Portfolio

Static portfolio website built with HTML, CSS and vanilla JavaScript.

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Customize
- Replace/add images inside `assets/`.
- Update links and text in `index.html`.
- Theme is controlled by the sun/moon button and saved in localStorage.

## Publish
This can be published as a static site using GitHub Pages, Vercel, Netlify, or similar hosting.
